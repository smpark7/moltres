ArrayBodyForce

Description

ArrayBodyForce applies body forces specified with functions to an array variable:

where is the test functions of all the components of the array variable , and is the body force functions whose size must agree with the number of components of the array variable. The Jacobian term for this kernel is zero since it is assumed that is not** a function of the unknown .

Example Input Syntax

[Kernels]
  [diff]
    type = ArrayDiffusion
    variable = u
    diffusion_coefficient = dc
  []
  [source]
    type = ArrayBodyForce
    variable = u
    function = '1 x'
  []
[]
(moose/test/tests/kernels/array_kernels/array_body_force.i)
